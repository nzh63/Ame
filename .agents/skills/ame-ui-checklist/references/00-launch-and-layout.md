# 00 — 启动应用 & 主界面布局

## 前置条件

- 已构建应用：`yarn tauri:dev`（开发模式）或运行打包后的 exe
- 操作系统：Windows 10/11

## Step 1: 启动应用

**开发模式：**
```bash
cd <项目根目录>
yarn tauri:dev
```

**打包模式：** 双击 `src-tauri/target/release/bundle/nsis/Ame_*_setup.exe` 安装后从开始菜单启动。

**✅ 通过标准：** 出现标题为 **"Ame - Visual Novel Translator"** 的窗口。

---

## Step 2: 认识主界面布局

窗口分为三个区域：

```
┌──────────────────────────────────────────────────┐
│  标题栏（可拖动）  Ame - Visual Novel Translator  │
├────────────┬─────────────────────────────────────┤
│            │                                     │
│  侧边栏     │         内容区域                     │
│  (深色)     │         (当前页面)                   │
│            │                                     │
│  · 主页     │                                     │
│  · 添加游戏  │                                     │
│  · 区域转换器│                                     │
│  · 翻译器设置│                                     │
│  · TTS设置  │                                     │
│  · OCR设置  │                                     │
│  · 分词设置  │                                     │
│  · 词典设置  │                                     │
│            │                                     │
└────────────┴─────────────────────────────────────┘
```

- **标题栏**：顶部，可拖动移动窗口
- **侧边栏**：左侧深色区域，包含所有导航菜单
- **内容区域**：右侧，显示当前选中页面的内容

---

## Step 3: 侧边栏导航

### 直接菜单项（点击即跳转）

| 菜单项 | 点击后显示 |
|--------|-----------|
| 主页 | 游戏库（Dashboard） |
| 添加游戏 | 添加游戏向导 |
| 区域转换器设置 | 区域转换器列表 |

### 子菜单（点击展开，再点击子项跳转）

| 菜单项 | 子项 |
|--------|------|
| 翻译器设置 | echo, OpenAI-Compatible, Anthropic, 百度AI, 腾讯云, JBeijing, DrEye, 百度翻译, 腾讯翻译君, 有道翻译, 谷歌翻译 |
| TTS设置 | 通用设置, WebSpeechSynthesisApi |
| OCR设置 | 通用设置, 百度AI开放平台, 腾讯云, PP-OCR |
| 分词设置 | 通用设置, intl-segmenter, mecab |
| 词典设置 | 通用设置, 有道词典, 沪江小D |

**操作：** 点击带箭头的菜单项 → 展开子菜单 → 点击子项 → 内容区域切换。

**✅ 通过标准：** 点击每个菜单项/子项后，内容区域正确切换，侧边栏高亮当前项。

---

## Step 4: 默认页面

首次启动时，默认显示 **主页（Dashboard）**。

**✅ 通过标准：** 内容区域显示游戏库页面（可能有游戏卡片，也可能为空）。
