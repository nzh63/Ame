# 04 — Provider 选项页 (翻译器 / TTS / OCR / 分词 / 词典)

**前置：** 应用已启动。展开侧边栏对应子菜单，点击一个 provider。

所有 provider 共用同一个选项页模板（Options.vue），根据 JSON Schema 动态渲染表单。

---

## 进入页面

| 操作 | 示例 |
|------|------|
| 展开 **翻译器设置** → 点击 **echo** | 显示 echo provider 选项 |
| 展开 **翻译器设置** → 点击 **OpenAI-Compatible** | 显示 OpenAI 选项（API Key、Model 等） |
| 展开 **TTS设置** → 点击 **通用设置** | 显示 TTS 管理器通用选项 |
| 展开 **OCR设置** → 点击 **通用设置** | 显示 OCR 提取器通用选项 |
| 展开 **分词设置** → 点击 **mecab** | 显示 MeCab 选项 |
| 展开 **词典设置** → 点击 **有道词典** | 显示有道词典选项 |

**✅ 通过：** 页面标题显示 providerId，下方显示描述文字和表单。

---

## 表单字段类型

| 字段类型 | 外观 | 操作 |
|----------|------|------|
| **枚举 (enum)** | 下拉选择框 | 点击展开，选择一个选项 |
| **字符串/数字** | 文本输入框 | 输入值；输入框右侧可能显示类型标签 |
| **可空字段** | 文本输入框 | 输入 `<null>` 表示空值 |
| **数组** | 多个输入框（按索引） | 逐个编辑 |

---

## 验证规则

| 输入 | 预期 |
|------|------|
| 数字字段输入文字 | 字段下方显示红色错误 **"应当是一个数字"** |
| 可空字段输入非法值 | 显示 **"应当为null（输入<null>）"** |
| 枚举字段 | 只能选择下拉列表中的值 |

**✅ 通过：** 非法输入时显示红色错误提示。

---

## 保存

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 修改字段后点击 **保存并应用** | — |
| 1a | 如果有验证错误 | 弹出黄色 toast **"请先修正输入错误再保存"**，不保存 |
| 1b | 如果无错误 | 弹出绿色 toast **"已成功保存"** |

**✅ 通过：** 有错误时阻止保存并提示；无错误时保存成功。

---

## 放弃

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击 **放弃** | 跳转回主页 |
| 2 | 有未保存修改时 | 路由守卫弹出确认框 |

---

## 空状态

如果某个 provider 没有可配置选项：

**✅ 通过：** 页面显示调整图标 + 文字 **"没有可以调整的选项哦"**。

---

## 特殊页面: TTS WebSpeechSynthesisApi

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 展开 TTS设置 → 点击 **WebSpeechSynthesisApi** | 显示语音相关选项 |
| 2 | 查看 voice 枚举字段 | 下拉列表包含系统已安装的语音（动态注入） |

**✅ 通过：** 语音下拉列表非空，包含系统语音。
