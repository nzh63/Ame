# 05 — 翻译悬浮窗 (TranslatorWindow)

**前置：** 已从主页启动一个游戏（流程见 [01-dashboard.md](./01-dashboard.md) 流程 A 或 B）。
游戏启动后，翻译悬浮窗自动弹出。

窗口结构：无边框窗口，顶部标题栏鼠标离开 1 秒后自动隐藏，鼠标移回时重新显示。

---

## 标题栏

将鼠标移到窗口顶部，标题栏显示：

```
[ 翻译 | 文本选择 | 提取设置 ]          [ — | ⏸ | 📌 ]
```

### 左侧：视图切换（单选按钮组）

| 按钮 | 操作 | 预期结果 |
|------|------|----------|
| **翻译** | 点击 | 切换到翻译视图（默认） |
| **文本选择** | 点击 | 切换到 Hook 选择视图 |
| **提取设置** | 点击 | 切换到提取设置视图 |

### 右侧：窗口控制

| 按钮 | 操作 | 预期结果 |
|------|------|----------|
| **—** (最小化) | 点击 | 窗口最小化到任务栏 |
| **⏸ / ▶** (暂停/继续) | 点击 | 暂停或恢复文本提取；图标切换 |
| **📌** (置顶) | 点击 | 窗口切换置顶状态；激活时图标旋转 -45° |

**✅ 通过：** 三个视图按钮切换内容；暂停后不再接收新文本；置顶后窗口保持在最前。

---

## 视图 1: 翻译 (默认)

显示提取到的文本列表（最多 10 条，最新在上）。

### 原文行

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 鼠标悬停在原文行上 | 触发分词，原文拆分为可点击的单词 |
| 2 | 点击某个单词 | 调用词典查询，显示释义 |
| 3 | 悬停在有 extraInfo 的单词上 | 显示 tooltip（读音/翻译） |

### 译文行

| 显示 | 含义 |
|------|------|
| 正常文本 | 翻译结果 |
| 红色文本 **"{id}发生错误：{msg}"** | 该 provider 翻译出错 |

### 右键菜单 / TTS

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 右键点击原文行（或长按 750ms） | 弹出上下文菜单 |
| 2 | 选择 TTS 朗读 | 调用 TTS 朗读该文本 |

**✅ 通过：** 悬停分词、点击查词、右键朗读均正常。

---

## 视图 2: 文本选择 (Hook Select)

点击标题栏 **文本选择** 进入。

| 元素 | 操作 | 预期结果 |
|------|------|----------|
| **清除按钮** (圆形 🗑) | 点击一次 | 清除已选中的 hookCodes |
| | 无选中时再点击 | 清除捕获的文本列表 |
| **单选模式** | 选择 | 后续选择替换当前 hook |
| **多选模式** | 选择 | 后续选择追加 hook |
| 文本列表项 - **使用中** (绿色 ✓) | 显示 | 表示该 hook 已被选中 |
| 文本列表项 - **使用** (🚀) | 点击 | 选中该 hook，开始提取；单选模式自动跳转翻译视图 |

**✅ 通过：** 点击"使用"后，翻译视图开始显示该 hook 的文本。

---

## 视图 3: 提取设置 (Extract Setting)

点击标题栏 **提取设置** 进入。

| 字段 | 操作 | 预期结果 |
|------|------|----------|
| **文本大小** 滑块 (6-100) | 拖动 | 翻译视图文字大小实时改变；松手后保存 |
| **提取方法** 下拉框 | 选择 Textractor / OCR | 切换提取方式；停止当前运行，清除 hook |
| **移除重复字符** 复选框 (仅 Textractor) | 勾选/取消 | 自动保存，立即生效 |
| **再次启动Ocr引导界面** 按钮 (仅 OCR) | 点击 | 弹出 OcrGuide 窗口（见 [06-ocr-guide.md](./06-ocr-guide.md)） |

**✅ 通过：** 文本大小改变可见；切换提取方法后 hook 被清除；OCR 按钮打开引导窗口。
