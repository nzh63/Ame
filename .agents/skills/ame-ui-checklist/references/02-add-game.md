# 02 — 添加游戏向导 (Add Game)

**前置：** 应用已启动。点击侧边栏 **添加游戏**。

页面顶部显示三步进度条：**① 选择游戏路径 → ② 设置启动参数 → ③ 检查配置**

---

## Step 1: 选择游戏路径

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在 **路径** 输入框右侧点击 **"打开..."** 按钮 | 弹出文件选择对话框（过滤 *.exe） |
| 2 | 选择一个 `.exe` 文件，点击"打开" | 路径填入输入框 |
| 3 | 观察 **标题** 输入框 | 自动填入 exe 文件名（不含扩展名） |
| 4 | （可选）手动修改标题 | 标题改变 |
| 5 | 点击 **下一步** | 进度条前进到 Step 2 |

**✅ 通过：** 进度条高亮第 2 步，显示启动参数表单。

---

## Step 2: 设置启动参数

| 字段 | 操作 | 说明 |
|------|------|------|
| **区域转换器** | 下拉选择 | 选项：`不转换` / 已保存的转换器（灰色=未启用）/ `自定义启动参数` |
| **启动参数** | 文本框 | 仅选择"自定义启动参数"时可编辑，否则灰色 |
| **提取方法** | 下拉选择 | `Textractor` 或 `OCR` |
| **HookCode** | 输入框 | 仅提取方法=Textractor 时可编辑，placeholder "可以留空" |

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 选择区域转换器（如 Locale Emulator） | 启动参数自动填入转换器命令 |
| 2 | 选择提取方法 | 选 OCR 时 HookCode 变灰 |
| 3 | 点击 **下一步** | 进度条前进到 Step 3，显示"加载中..." |
| 3' | 点击 **上一步** | 返回 Step 1 |

**✅ 通过：** 进入 Step 3 加载状态。

---

## Step 3: 检查配置

页面显示加载动画 **"加载中..."**，后台验证配置并尝试启动游戏。

**✅ 通过：** 加载完成后自动跳转到结果页（Step 4）。

---

## Step 4: 结果

### 成功

| 显示 | 操作 |
|------|------|
| ✓ 图标 + **"添加成功"** | 点击 **完成** → 跳转回主页，游戏卡片出现 |

### 失败

| 显示 | 操作 |
|------|------|
| ✗ 图标 + **"添加失败"** + 错误信息 | 两个按钮可选 |
| | **重新添加** → 返回 Step 1 重新配置 |
| | **仍然使用当前配置** → 强制保存游戏并跳转主页 |

**✅ 通过（成功路径）：** 主页出现新游戏卡片。
**✅ 通过（失败路径）：** 点击"重新添加"回到 Step 1；点击"仍然使用"后主页出现卡片。
